# rx-switch

English | [中文](README.md)

One keyboard and mouse for multiple Windows and macOS computers.

![rx-switch](screenshot.png)

- Move across screen edges to switch devices; drag screens to arrange them.
- Encrypted LAN connections with pairing codes, supporting up to 8 agents.
- Automatic ⌘ / Ctrl mapping and a shortcut to return to the local computer.
- Automatic reconnection with manual stop.
- System tray, Chinese and English, live link and traffic statistics.
